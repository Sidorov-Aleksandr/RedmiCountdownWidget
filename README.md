# Redmi Countdown Widget
Обратный отсчёт до 2 мая 2027, 00:00 (часовой пояс телефона).

Сборка: Actions → Build Android APK → последний успешный запуск → Artifacts → RedmiCountdownWidget-APK.
Скачайте ZIP с APK на Redmi, распакуйте и установите app-debug.apk.
Добавьте виджет через меню «Виджеты» рабочего стола.
Android может обновлять данные виджета с задержкой (обычно не чаще 30 минут); при нажатии на виджет откроется приложение и обновит показания.
